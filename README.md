# Delivery Performance Analysis

A Python-based data analysis project focused on understanding delivery performance and predicting delivery times using machine learning.

## About the Project

This project explores delivery data to understand the factors that affect delivery time, delays, and failed deliveries. It also compares machine learning models to find a suitable model for predicting delivery time.

## Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## What I Did

- Explored and prepared the delivery dataset.
- Cleaned data and handled categorical features.
- Analyzed delivery patterns based on distance, weather, vehicle type, delivery mode, and delivery partner.
- Built and compared Linear Regression and Decision Tree Regression models.
- Evaluated model performance using MAE, RMSE, and R² score.
- Suggested ways to improve delivery planning.

## Results

Linear Regression performed best among the evaluated models.

- MAE: 1.283 hours
- RMSE: 1.622 hours
- R² Score: 0.728
